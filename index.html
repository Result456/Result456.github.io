SECTION A · REFLECTION

My Learning Reflection

The STAR method: Situation, Task, Action and Result.

Introduction

In this project I created a digital portfolio using GitHub. The portfolio included my CV written in Markdown, a mock interview video and publishing the project using GitHub Pages. At first I found the process difficult because I was not familiar with GitHub and Markdown. However, as I continued practicing, I improved my skills and gained confidence.

This section is now presented in HTML alongside Section B. The reflections below describe my experience of the original Markdown assignment.

Reflection on Coding in Markdown

Situation

At the beginning I had little knowledge of Markdown language and how to structure a CV using it.

Task

My task was to create a professional CV using Markdown and make sure it was clear, well-structured and readable.

Action

I learned basic Markdown syntax such as headings, lists and links. I practiced formatting my CV step by step and corrected my mistakes. I also made sure my content was neat and organized.

Result

I was able to successfully create a CV using Markdown. My work became more structured and I now understand how to use Markdown for future projects.

Reflection on Mock Interview Video

Situation

I was required to record and include a mock interview video in my portfolio.

Task

My task was to create a clear and professional video and include it in my GitHub portfolio using Markdown or HTML.

Action

I recorded my video and uploaded it to Google Drive. Then I learned how to insert the video link into my Markdown file. I also ensured that the link was accessible to everyone.

Result

I successfully included the video link in my portfolio. This improved my confidence and helped me understand how to present myself professionally online.

Reflection on the Use of GitHub Pages

Situation

I had never used GitHub Pages before and did not understand how to publish a website.

Task

My task was to publish my portfolio online using GitHub Pages so that it could be accessed publicly.

Action

I followed the steps to create a repository, upload my files and enable GitHub Pages. I practiced until my site was visible online.

Result

I successfully published my portfolio. Now I understand how websites can be hosted using GitHub, and I feel more confident using this platform.

Conclusion

This project helped me improve my technical skills, especially in Markdown and GitHub. I also learned how to present my work professionally. Even though I faced challenges at the beginning, I was able to overcome them through practice and patience.

Reflection · Three Weeks of Agile Practice

Situation

Over three weeks, the CivicFix team worked toward testing the application while the backend was not ready, photo sets were limited and connectivity was sometimes lost.

Task

My task was to test the features that were available, prepare privacy-safe test data and report the results honestly.

Action

In Week 1, I drafted and reviewed UAT-01 to UAT-13 and prepared test photos with Olona. In Week 2, I ran UAT-01 to UAT-03 with example data, logged issues for Mpho and retested fixes. In Week 3, I tested duplicate checks, staff-side features and privacy notices, and compared model predictions with labelled photos.

Result

I learned that testing starts with understanding requirements, and that feedback and retesting improve the product. I also learned to report limitations honestly instead of claiming a fully working live system or a completed final test run. In a future sprint, I would agree testable acceptance criteria and integration checkpoints earlier, prepare more varied privacy-safe photos, and reserve time for regression testing.
